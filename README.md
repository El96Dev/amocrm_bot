## Описание
Данный бот позволяет ежедневно получать статистику по сделкам каждого меннеджера из сервиса amocrm.
## Инструкция по запуску
### Создание бота
Для запуска данного приложения необходимо найти в телеграме бота BotFather
- Отправьте в чат с BotFather команду /newbot.
- Введите название бота — в этой категории особых ограничений нет.
- Введите юзернейм бота — его техническое имя, которое будет отображаться в адресной строке. К нему уже больше требований: юзернейм должен быть уникальным, написан на латинице и обязательно заканчиваться на bot. Так «Телеграм» защищается от злоумышленников, которые могут выдавать ботов за реальных людей.
- Готово. BotFather пришлет токен бота — его можно использовать для настройки в сторонних сервисах.

### Создание .env файла
Далее в корне проекта необходимо создать файл .env со следующими строчками:
```
TELEGRAM_TOKEN=your_token
REPORT_HOUR=21
REPORT_MINUTE=00

POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_DB=amocrm_bot
POSTGRES_HOST=pgdb
POSTGRES_PORT=5432

DB_USER=postgres
DB_PASSWORD=postgres
DB_NAME=amocrm_bot
DB_HOST=pgdb
DB_PORT=5432

TZ=Europe/Samara

CELERY_BROKER_URL=redis://redis:6379/0
CELERY_RESULT_BACKEND=redis://redis:6379/0
```
В переменную `TELEGRAM_TOKEN` необходимо добавить полученный у BotFather токен. Также можно изменить занчения `REPORT_HOUR` и `REPORT_MINUTE`, чтобы настроить время отправки сообщений со статистикой.
### Создание приватной интеграции:
Создайте приватную интеграцию, руководствуясь примером из документации amocrm: https://www.amocrm.ru/developers/content/oauth/step-by-step
### Запуск приложения
Для запуска приложения необходимо установить Docker. Далее, откройте директорию с приложением amocrm_bot в терминале и введите команду: `docker compose up --build`
Используйте команду `/auth`, чтобы ввести необходимые данные из приватной интеграции. После успешной авторизации, каждый день в указанное в .env вермя в чат бота будут приходить уведомления о суммарной выручке менеджеров.
